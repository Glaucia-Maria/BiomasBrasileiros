# 🌿 Biomas Brasileiros — Entre a Natureza e a Destruição

Um projeto interativo sobre os seis biomas brasileiros, desenvolvido para promover a conscientização ambiental e refletir sobre os impactos da degradação da natureza na vida cotidiana.

A proposta conecta preservação ambiental e sociedade, abordando questões como escassez de água, secas, enchentes, produção de alimentos e perda de biodiversidade.

## 🎯 Objetivo

Desenvolver uma experiência interativa que una tecnologia, educação ambiental e conscientização social, aplicando conceitos de programação e desenvolvimento de interfaces.

Projeto acadêmico desenvolvido para a disciplina de **Programação Móvel**.

## 🌎 Biomas contemplados

- 🌳 Amazônia
- 🌾 Cerrado
- 🌱 Mata Atlântica
- 🌵 Caatinga
- 🐎 Pampa
- 🐊 Pantanal

Cada bioma possui identidade visual própria, informações ambientais e reflexões sobre as consequências de sua degradação para a sociedade.

## ✨ Funcionalidades

- **Exploração dos biomas:** apresentação dos seis biomas brasileiros em cards interativos.
- **Detalhes personalizados:** imagens, indicadores ambientais e críticas socioambientais.
- **Navegação entre telas:** utilização de `Navigator.push` e `Navigator.pop`.
- **Identidade visual temática:** cores e imagens inspiradas nas características de cada bioma.
- **Interatividade:** animações, transições e gestos de toque.
- **Carregamento de imagens:** tratamento visual para carregamento e falhas.
- **Conscientização ambiental:** reflexões sobre a relação entre degradação ambiental e qualidade de vida.

## 🛠️ Tecnologias utilizadas

- [Flutter](https://flutter.dev/) — desenvolvimento da interface.
- [Dart](https://dart.dev/) — linguagem de programação.
- **Material 3** — componentes e identidade visual.
- **Navigator** — navegação entre telas.
- **List<Map<String, String>>** — estrutura de armazenamento dos dados.
- **Image.asset** — carregamento de imagens locais.

O projeto utiliza recursos nativos do Flutter, sem dependências externas adicionais.

## 🌱 Impacto socioambiental

A degradação dos biomas brasileiros não representa apenas a perda de vegetação e biodiversidade. Ela também pode comprometer a disponibilidade de água, a produção agrícola, a regulação climática e as condições de vida de diferentes comunidades.

O projeto propõe uma reflexão:

**Quando um bioma é destruído, quais consequências chegam até a nossa vida cotidiana?**

Os indicadores ambientais devem ser acompanhados de fontes e períodos de referência para garantir a confiabilidade das informações apresentadas.
